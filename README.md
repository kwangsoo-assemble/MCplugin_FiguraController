# MCplugin_FiguraController

> A **server-owned state & signal** plugin for a custom-forked Figura environment (Paper / Purpur **1.21.8**).
> The server holds player, mob and global "states" and sends only what changed to the clients that need to see it.
> The forked Figura client receives them and exposes them to avatar Lua as `server_data`.

| | |
|---|---|
| Server | Paper / Purpur 1.21.8 · Java 21 |
| Required plugin | **FiguraFSB** — [MCplugin_FiguraFSB_quadaFork](https://github.com/kwangsoo-assemble/MCplugin_FiguraFSB_quadaFork) |
| Companion client | **Figura fork** `0.1.6-but-ai-edited.1` or later — [MCmod_Figura_quadaFork](https://github.com/kwangsoo-assemble/MCmod_Figura_quadaFork) (the official Figura cannot receive states) |
| Protocol | a single FSB custom packet `figuracontroller:v1` (binary · once at the end of a tick · changes only) |
| License | MIT |

⚠ Source comments and the full documentation (`API.md`) are in **Korean**.

## What it does

```
[server]  FiguraController ── state store (players · mobs · global) · persistence · expiry · presets · /fc
            ▲ Java API · Bukkit events
            │  FSB packet "figuracontroller:v1"
            ▼
[client]  Figura fork ── client-wide store (outside avatars) → Lua global `server_data`
```

- **State** — a persistent value (JSON). The subject is a player, a mob (entity UUID) or global. Writing the same value again does nothing
  - `persist` (on by default) — saved by the server (players = files · mobs = entity PDC · global = file)
  - `private` — for a player, only that player's client · for a mob, server only
  - `expire` — removed automatically after N ticks
- **Signal** — a one-shot "do this now". Receivers: clients tracking the subject (default) · self · everyone · a list of players
- **Receivers** — player and mob states go only to clients that are **tracking** the subject (plus the player). Everything is sent the moment
  a client starts tracking it, and the client drops it when tracking ends
- **Avatar → server** — a host avatar sends a signal with `server_data:send(name, data)` (signals sent by someone else's avatar copy are dropped)
- **Replay (Flashback)** — the client fork writes the whole store into every recording snapshot, so seeking restores the values of that moment

## Usage (short)

```
/fc state set Steve skin "A"
/fc state set Steve buff true --transient --expire 200
/fc state set global mode "race"
/fc signal Steve SCREENSHAKE [1,2,3] --to all
/fc status
```

```java
FiguraControllerAPI api = FiguraController.api();
api.set(player, "skin", new JsonPrimitive("A"));
api.sendSignal(player, "SCREENSHAKE", data, Audience.ALL);
api.global().set("mode", new JsonPrimitive("race"));
```

```lua
local skin = server_data:get("skin")               -- own value · falls back to the global value
server_data.STATE_CHANGED:register(function(name, new, old, subject, initial) end)
server_data.SIGNAL:register(function(name, data, subject) end)
server_data:send("JUMP_PAD", { power = 3 })         -- host avatar only
```

- **Full usage** (Java API · Bukkit events · `/fc` · Lua · receivers · storage format · config · diagnostics) — [`API.md`](API.md) (Korean)
- CommandHelper functions (`fc_state_set` and so on) come from a separate CommandHelper extension — not in this repository

## Storage · config

```
plugins/FiguraController/
  config.yml               commandFeedback · debug · saveDelayTicks · oldCoreWarnTicks
  global.json              global states
  players/<uuid>.json      player states
  presets/<name>.json      presets (default is created on first run)
entity PDC  figuracontroller:states   mob states
```

## Building

Requires a Java 21 **JDK**.

```bash
# 1) Build FiguraFSB and install its jar into the local Maven repository (provided dependency)
./mvnw install:install-file -Dfile=<FiguraFSB jar> \
    -DgroupId=org.figuramc.figura -DartifactId=figura-fsb-spigot -Dversion=0.1.6 -Dpackaging=jar
# 2) Build and test
./mvnw package          # → target/figuracontroller-<version>.jar
```

## Protocol codec

`src/main/java/kr/asmbl/figuracontroller/protocol/` is the **source of truth**. The client fork (MCmod_Figura_quadaFork) carries a copy of
the same files — change both together when the protocol changes. Test vectors are in `src/test/resources/figuracontroller/vectors.json`
(generated by a separate reference implementation).
